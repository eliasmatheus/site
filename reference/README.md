# Referência

Material de consulta. Nada daqui vai para produção.

- `prototype/World.dc.html`: protótipo da v2 (mundo 3D), artboard 4 do canvas. Formato do Claude Design: markup `<x-dc>` com `{{ }}` e `<sc-for>`/`<sc-if>`, e a lógica na `class Component extends DCLogic` no fim do arquivo. Não roda fora do canvas. Caminhos `/_blob/...` foram trocados por `../../public/assets/...`.
- `prototype/Journey.dc.html`: protótipo da v1 (página longa), artboard 3, com capítulos que ainda não estão na v2 (pranchas CAD, conformidade, automação, CS50, Interfaces, Method, Worlds, Time, Epilogue). Tem nomes reais que não devem ir para o site; ver `docs/conteudo-e-privacidade.md`.
- `prototype/landing-orbit.html`: protótipo da landing TL;DR, direção Orbit escolhida (a Brief ficou no mesmo arquivo, atrás do seletor). HTML puro; abre direto no navegador. Versão viva: https://claude.ai/artifact/KvEF6mQDUStqXK5CmtzHa1
- `prototype/black-hole.html`: protótipo da abertura Horizon (shader de buraco negro com a luz curvada passo a passo, planeta arrastável com relógio próprio). Enquadramento escolhido: Off-axis. HTML puro. Versão viva: https://claude.ai/artifact/4aFGXG6sZ5XPprmWWgzfQP
- `prototype/the-fall.html`: protótipo do The fall v2 (queda por dentro de uma estrutura de vigas em three.js, momentos por brechas, virada para estética retrô). HTML puro, three.js via CDN. Versão viva: https://claude.ai/artifact/GiNRNckPdZp1nwjKHHDxSv
- `prototype/my-computer.html`: protótipo do My computer (a história pelas versões do Windows, do Pentium à escolha do curso). HTML puro. Versão viva: https://claude.ai/artifact/GBwWSsau8tqyK6c7Rmf61j
- `prototype/os-slice-2000-xp.html`: fatia vertical do My computer como pseudo-simulador em tela cheia (Windows 2000 → XP: discagem com som sintetizado, a hora semanal com portal de jogos em Flash e cache offline, luta de bonecos de palito, mensageiro, setup com partições, tela azul, emulador com cartuchos originais e corrida pseudo-3D, P2P e torrent). HTML puro. Versão viva: https://claude.ai/artifact/VYdAsy9n24hShjCCUwcpZ3
- `prototype/os-95-98.html`: My computer do primeiro PC ao Windows 98 (tela CRT ligando, POST com teste de memória, splash, Welcome, setup do 98, o arquivo na pasta do jogo). HTML puro. Versão viva: https://claude.ai/artifact/8h4TSUesujyg8a2Qz5zNNQ
- `prototype/os-xp-8.html`: My computer do XP ao Windows 8 em monitor LCD (UAC, tutorial e editor de imagem, scanner de memória no modo carreira, lobby de mapas personalizados, e-mail com a key beta, primeira partida, tiles do 8 com a escolha do curso). HTML puro. Versão viva: https://claude.ai/artifact/DuhPQSSVr8eu8ERxxzB46y
- Versão viva dos dois primeiros: https://claude.ai/artifact/6tvLdr8KsgChtDpNwAdp1i (usar o Play).
- `originals/desafio-calculadora/`: a calculadora entregue em julho de 2020.
- `originals/python/`: os dois primeiros exercícios em Python.
- `screens/`: prints de problemas encontrados nos testes (ex.: sapata no mobile).
