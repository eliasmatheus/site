## Intenção

Uma tela contínua de Windows de 2020, como se o visitante estivesse usando o computador do Elias. Do anúncio à calculadora entregue: três tecnologias que ele nunca tinha tocado, aprendidas em sequência.

## Beats

1. **Feed** (rede social genérica, sem marca): anúncio de um bootcamp de front-end, conta "frontend.bootcamp". 16 meses, intensivo como um emprego, paga só quando contratado, seleção com desafios. NUNCA usar o nome real da escola.
2. **Chat** de 25/05/2020 com "[a friend]" (nunca o nome): as frases reais em português com tradução em inglês. Ele não foi sozinho.
3. **E-mail**: "Desafio: Calculadora", A + B com HTML, CSS e JavaScript, cada uma marcada ✗.
4. **HTML**: editor estilo Sublime (Monokai) com os arquivos reais da pasta do curso; `primeiro.html` só com texto ("Olá! Esta é a minha primeira página."), abre no Chrome em Times New Roman ("Arquivo | C:/Users/Usuário/Desktop/curso/..."). Depois `<h1>`, `<p>`, `<strong>`, cada um mudando o navegador. Por fim, o editor vira de verdade: o visitante digita e o navegador renderiza ao vivo. Polaroid da mesa de 2020.
5. **CSS**: bloco `<style>` crescendo (título azul, Arial, parágrafo cinza, centralizado com fundo) e o navegador aplicando.
6. **JavaScript**: a primeira versão real ("Calculadora Simples", A + B = C, função vazia `// body...`) com a polaroid da tela original; clicar em Calcular não faz nada. Depois as perguntas: como o JS lê um input (getElementById), como escrever uma função (onclick), e a mais cruel: que nome dar à variável (x, a, numero, primeiroValor, valorDoPrimeiroInput, riscando até n1 ✓). Number(), resultado. Por fim a versão entregue ("Calculadora Básica") ganhando os extras que ninguém pediu: card, sombra, ícone, botão Zerar. "Submitted in July 2020."

## Regras

- Visual de Windows 10 genérico (barra de tarefas, janelas). Não usar logos ou ícones oficiais da Microsoft, Google, Sublime ou Instagram; recriar formas neutras.
- Preview ao vivo do HTML do visitante: renderizar com um parser próprio restrito (como no protótipo) ou num `<iframe sandbox>` sem scripts. Nunca `innerHTML` direto do input.
- Fotos como polaroids levemente inclinadas, com legenda.

## Mobile

Trocar o desktop do Windows por um celular de 2020: feed e chat são naturais no celular. Editor e navegador alternam em tela cheia com uma aba "Code | Preview" e o scroll avança os passos. Barra de tarefas some.
